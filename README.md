# Paytm Digital Payment Analytics Dashboard 📊

An interactive, end-to-end data analytics solution built using **Excel** for data processing and **Power BI** for advanced data modeling and dashboard visualization. This project transforms raw transaction logs into actionable business insights for digital wallet platforms.

---

## 🚀 Key Visual Highlights & Insights

*   **Financial Metrics (KPIs):** Tracks **\$3M in Total Revenue** across **500 Total Transactions**, with an **Average Transaction Value of \$5.17K** and **\$19.36K in Total Cashback**.
*   **Geographic & Merchant Analysis:** Highlights top-performing cities (led by *Hyderabad*, *Nashik*, and *Ahmedabad*) and charts revenue distribution among primary merchants like *DMart*, *Flipkart*, and *Zomato*.
*   **Customer Segmentation:** Breaks down user demographics into four distinct tiers: *Premium* (28.2%), *Regular* (27.6%), *Silver* (25.6%), and *Gold* (18.6%).
*   **Payment Method Preferences:** Visualizes transactional distributions across *Credit Cards*, *Debit Cards*, *Net Banking*, *UPI*, and *Wallets*.

---

## 🛠️ Tech Stack & Skills Demonstrated

*   **Excel:** Used for initial data preparation, cleaning, structuring, and tabular formatting.
*   **Power BI Desktop:** Implemented for Data Modeling (star schema), DAX measures, and creating interactive visualization sheets.
*   **Data Visualization:** Applied dashboard design best practices, including custom KPI cards, donut charts, funnel line graphs, and horizontal bar charts.

---

## 📂 Project Structure

*   `data/` - Contains the source Excel datasets (or sample mock data).
*   `reports/` - Contains the exported Power BI `.pbix` file.
*   `images/` - Dashboard screenshots and visual assets.
